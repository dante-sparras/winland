# The spec is a pinned Hyprland release

Winland matches one Hyprland release tag, set in `dev.ps1`. The manual and source cloned there are the spec, and the Gaps are listed against that tag. Moving to a newer tag is its own change, driven by a diff of what Hyprland changed.

Hyprland changes quickly, and tracking `main` would make "matches Hyprland" mean something different each week.
