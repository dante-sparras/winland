# A pure core with a thin Windows adapter

Layouts, config parsing, Dispatcher logic and Workspace state live in a core project that references no Win32. A thin Windows adapter feeds it OS events and applies its results with Win32 calls generated by CsWin32. `winlandctl` is a separate project and executable.

Layouts and config are pure algorithms, and Win32 work (hooks, `SetWindowPos`) can't be unit-tested. This split lets the core be tested with plain unit tests and no real windows.
